
# 1. 全章主线

本章要回答三个问题：

1. **性能如何描述？** 分清零偏、稳定性、重复性、标度因数及随机游走。
2. **误差从哪里来？** 分清静态误差、动态误差与随机误差。
3. **参数如何测出？** 用地球自转和重力场提供参考输入，通过不同姿态使不同误差项显现，再解方程。

**理解重点：测试位置不同，受到激励的模型项不同；没有被激励或始终耦合的参数，不能单独辨识。**

# 2. 惯性器件的主要技术指标

## 2.1 陀螺仪指标

| 指标 | 核心含义 | 复习要点 |
| --- | --- | --- |
| 量程 | 正、反方向可检测的最大输入角速率 | 是输入范围 |
| 零偏 bias | 零输入角速率下的平均输出，折算到输入端 | 是均值，常用单位为 °/h |
| 零偏稳定性 | **一次上电期间**，输出围绕均值的离散程度 | 按课件，用规定时间内输出的标准差表示 |
| 零偏重复性 | **多次上电之间**，各次测得零偏的一致程度 | 对每次测试的零偏均值再求标准差 |
| 漂移 drift | 单位时间内陀螺轴相对惯性空间的方位偏差角 | 单位为 °/h，分系统性漂移与随机漂移 |
| 标度因数 scale factor | 输出变化量与输入角速率变化量之比 | 输入输出拟合直线的斜率 |
| 阈值 | 能敏感的最小输入角速率 | 从零附近判断能否检测到输入 |
| 分辨率 | 在给定输入下，能敏感的最小输入角速率增量 | 判断能否分辨输入的微小变化 |
| 带宽 | 能准确测量输入角速度的频率范围 | 范围越大，动态响应能力越强 |

**标度因数与非线性：** 拟合斜率表示比例关系，拟合残差反映实际输入输出偏离直线的程度。还可考察其稳定性、重复性、正负输入不对称性及温度灵敏度。

**系统性漂移与随机漂移：** 前者具有规律，可通过模型补偿；后者难以确定性补偿，是评价精度的重要依据。

## 2.2 角随机游走：记住单位与时间关系

输出角速率中的白噪声经过积分，形成随机角误差。其标准差随时间的平方根增长，可记为：

$$
\sigma_\theta(t)\propto N\sqrt{t}
$$

其中角随机游走系数 $N$ 的常用单位为：

$$
{}^\circ/\sqrt{\mathrm{h}}
$$

**易混点：** 漂移率用 °/h，角随机游走系数用 °/√h；前者与后者不能直接当作同一指标比较。上式是对课件文字的整理，时间单位应与系数匹配。

## 2.3 精度等级：记量级

采用的惯性级概念：运行1 h，水平定位误差优于1 n mile，简称“1 n mile/h”。这里应按**运行1小时后的定位误差**理解。

$$
\omega_{ie}\approx15^\circ/\mathrm{h},\qquad
1\,\mathrm{meru}=0.015^\circ/\mathrm{h}
$$

其中 meru 为毫地转率，即地球自转角速率的千分之一。

课件给出的惯性级典型要求：

- 陀螺精度约 $0.01^\circ/\mathrm{h}$。
- 加速度计精度约 $10^{-4}g$，其中 $g\approx9.8\,\mathrm{m/s^2}$。
- 课件说明：上述陀螺误差可引起约1 n mile/h的定位误差，加速度计误差可引起约0.3 n mile/h的定位误差。**这些是课件给出的量级关系，不是任意系统通用的精确换算式。**

不同等级IMU的零偏典型值：

| 等级（课件英文） | 加速度计零偏 / mg | 陀螺零偏 / (°/h) |
| --- | ---: | ---: |
| 航海级 Marine | 0.01 | 0.001 |
| 航空级 Aviation | 0.03—0.1 | 0.01 |
| 中间级 Intermediate | 0.1—1 | 0.1 |
| 战术级 Tactical | 1—10 | 1—100 |
| 汽车级 Automotive | >10 | >100 |


# 3. 误差模型（了解即可）

## 3.1 三类模型

| 类型 | 主要自变量 | 描述的误差 |
| --- | --- | --- |
| 静态误差模型 | 比力 $f$ | 误差随线运动输入、重力投影等变化的关系 |
| 动态误差模型 | 角速度 $\omega$、角加速度 $\dot\omega$ | 角运动引起的附加误差 |
| 随机误差模型 | 随机过程及统计参数 | 难以由确定性机理完整描述的误差 |

**“静态误差模型”不等于“只有静止时才有误差”**：课件按其与比力输入的关系分类。建模方法包括理论建模和试验建模。

## 3.2 陀螺仪静态误差模型

对于课件中的单自由度转子陀螺，$I$、$O$、$S$ 分别表示输入轴、输出轴、自转轴。完整的二阶静态漂移模型为：

$$
\begin{aligned}
\omega_d={}&D_F+D_If_I+D_Of_O+D_Sf_S\\
&+D_{IO}f_If_O+D_{OS}f_Of_S+D_{SI}f_Sf_I\\
&+D_{II}f_I^2+D_{OO}f_O^2+D_{SS}f_S^2.
\end{aligned}
$$

**记忆结构：1个常值项 + 3个一次项 + 3个交叉项 + 3个平方项，共10个系数。**

## 3.3 动态误差与陀螺补偿

动态模型可含角加速度项、角速度乘积项及高次项。课件给出的简化形式为：

$$
\delta\omega_I=K_O\dot\omega_O+K_{SI}\omega_S\omega_I.
$$


暂不考虑随机误差时，测量模型为：

$$
\widetilde\omega_I=\omega_I+\omega_d+\delta\omega_I.
$$


## 3.4 加速度计静态模型与补偿

引用《GJB 2504-95 石英挠性加速度计通用规范》的模型：

$$
\frac{E}{K_1}=K_0+a_i+K_2a_i^2+K_3a_i^3
+K_{ip}a_ia_p+K_{io}a_ia_o+\delta_oa_p+\delta_pa_o.
$$

其中 $i,p,o$ 分别对应输入基准轴、摆基准轴、输出基准轴；$a_i,a_p,a_o$ 为对应分量，按课件以 $g$ 为单位表示。

| 参数 | 含义 |
| --- | --- |
| $K_0$ | 偏值，单位为 $g$ |
| $K_1$ | 标度因数，如 V/g、mA/g |
| $K_2,K_3$ | 二阶、三阶非线性系数 |
| $K_{ip},K_{io}$ | 交叉耦合系数 |
| $\delta_o,\delta_p$ | 失准角，单位为 rad |

课件简化补偿式为：

$$
a_i=k_iE-K_0-K_2a_i^2.
$$

**理解：** 先将输出换算到输入端，再扣除偏值及非线性误差。该式右端仍含真实输入 $a_i$，属于隐式关系；实际求值还需近似或求解，不能直接当作只含 $E$ 的显式公式。


# 4. 标定的共同原理

## 4.1 测试目的分类

| 测试类型 | 目的 |
| --- | --- |
| 研究性测试 | 研究机理、发现缺陷，改进设计与工艺 |
| 鉴定性测试 | 按验收要求判断性能是否合格 |
| 应用性测试 | 掌握误差规律，辨识模型并进行补偿 |

## 4.2 系统辨识思路

**提供精确输入 → 准确测量输出 → 数据处理 → 求模型系数。**

地球提供两种天然参考输入：

- **地球自转角速度**：用于陀螺测试，需考虑输入轴方向上的投影。
- **当地重力加速度**：改变姿态，得到各轴不同的比力投影。

静止在地面不代表陀螺的输入角速率为零：它仍可能敏感地球自转。

## 4.3 最小二乘法：全章通用工具

把不同测试位置的测量方程叠成：

$$
\mathbf y=\mathbf A\mathbf x+\boldsymbol\varepsilon.
$$

当 $\mathbf A$ 列满秩时：

$$
\widehat{\mathbf x}=(\mathbf A^T\mathbf A)^{-1}\mathbf A^T\mathbf y.
$$

- $\mathbf y$：实测输出，或扣除已知真实输入后的误差。
- $\mathbf A$：由姿态角、已知输入等组成的设计矩阵。
- $\mathbf x$：待辨识系数，可能是原始误差系数，也可能是其组合。

**关键不是只增加采样数，而是使矩阵列独立。** 如果两个参数总以同一组合出现，再多重复采样也不能把它们分开。

# 5. 陀螺仪的主要测试方法

## 5.1 方法总览

| 方法 | 主要作用 | 核心特点与限制 |
| --- | --- | --- |
| 极轴翻滚| 辨识多项静态漂移系数及组合 | 输入轴不敏感地球自转；仍存在参数耦合 |
| 地理坐标八位置翻滚 | 估计一次项及零次、平方项的组合 | 操作直观，但无法激励交叉项 |
| 固定位置综合漂移 | 测一次启动稳定性、多次启动重复性 | 主要通过统计处理评价随机漂移 |
| 伺服转台试验 | 测长期漂移，模拟平台惯导工作状态 | 陀螺与转台构成闭环 |

## 5.2 极轴翻滚（静态误差）

转台旋转轴与地球自转轴平行，固定在转台上的陀螺仪各轴相对于重力场的方向会周期性改变。

目的是让重力这个恒定的比力，在不同方向上“扫过”陀螺仪，从而激励并辨识出那些与比力相关的误差项

## 5.3 地理坐标八位置翻滚（静态误差）

地理位置翻滚试验中，陀螺仪沿当地地理坐标系取向，每次只有陀螺仪的一个轴向(天向或地向)  存在比力激励，因此无法求得交叉轴误差系数，只能估计出零次、一次及平方误差系数

陀螺各轴沿东 E、西 W、南 S、北 N、天 U、地 D 取向，每个位置仅一轴具有非零比力投影。

**处理原则：先从输出中减去该位置的地球自转投影，才得到漂移。** 

**为什么有局限？**

1. 每次仅一轴有非零比力，故 $f_If_O,f_Of_S,f_Sf_I$ 始终为零，无法求交叉耦合系数。
2. $D_F$ 与平方项耦合，不能把这4个系数全部独立求出。
3. 若根据器件特性可忽略 $D_{OO}$，课件才进一步近似求出 $D_F,D_{II},D_{SS}$。

## 5.4 固定位置综合漂移：稳定性与重复性

统一的样本标准差公式为：

$$
s_\omega=\sqrt{\frac1{n-1}\sum_{k=1}^{n}(\omega_k-\bar\omega)^2}\qquad
\bar\omega=\frac1n\sum_{k=1}^{n}\omega_k
$$

| 项目 | 测试步骤 | $\omega_k$的含义 |
| --- | --- | --- |
| 一次启动稳定性 | 固定基座，启动稳定后按固定间隔记录，课件举例每5 min一次 | 同一次启动中的各次输出角速率 |
| 逐次启动重复性 | 每次启动稳定后记录一段数据求均值，停机冷却，再重复启动；课件举例每次记录30 min | 第 $k$ 次启动的平均输出角速率 |

**记忆：稳定性看“一次内散不散”，重复性看“多次间偏不偏”。**

## 5.5 伺服转台测试

将陀螺仪的输入轴对准转台主轴。当陀螺仪敏感到地球自转分量（或存在的漂移）时，会产生一个电信号。这个信号经放大后，不是用于反馈给陀螺仪自身的力矩器（那是力反馈测试），而是直接驱动伺服转台电机，使转台朝着减小该输出信号的方向转动

**转台角速率 = - (地球自转分量 + 陀螺漂移)**

- 若漂移可忽略，转台约以地球自转角速度反向旋转，转一周约需24 h，因此测试很慢。
- 若恰有 $\omega_d=-\omega_{ie}$，则 $\omega_{BT}=0$，转台不转；**不能据此认为陀螺没有漂移**。

# 6. 加速度计重力场试验

## 6.1 原理与限制

核心原理是利用地球重力这个天然的、已知的“1g 恒定基准”，通过改变加速度计的姿态，让重力在其各敏感轴上产生已知且可变的输入分量，从而激励并分离出加速度计的静态误差模型系数。

用当地重力在加速度计各轴上的投影提供参考输入，借助分度头改变安装角度。

- 优点：是最常用、最基本的性能测试方法。
- 限制：各轴可提供的比力分量不超过 $\pm1g$，因此对非线性系数、交叉耦合系数的标定精度有限，不能直接覆盖更大量程。
