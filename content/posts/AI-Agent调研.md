## Agent工具发展如此蓬勃，该如何有效学习？

跟紧核心团队产品，以第一性原理跟踪掌握源头工具，如claude团队、codex团队、openclaw团队等

## Agent核心概念

- subAgent 调用、自定义等使用
- MCP
- Agent SDK 开发
- Skills 配置、优化、自定义助理
- hooks 原理、如何自动化工作流

- sessions 多记忆存储方式
- CLAUDE.md 中内容，如永久指令
- automemory 记忆原理

## Agent 使用巧思

- 学习一门新知识时，利用Agent生成一系列结构化的核心问题及解答，快速把握知识体系结构
